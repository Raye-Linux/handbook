# Premiers pas

## Le bureau

La barre du bas fonctionne comme celle que vous connaissez : le bouton
avec l'œil Raye ouvre le menu Démarrer, vos applications ouvertes sont au
milieu, l'heure, le réseau et le son à droite.

## Les raccourcis

| Touches | Ce que ça fait |
|---|---|
| ⊞ | Ouvrir le menu Démarrer |
| ⊞ + E | Ouvrir l'explorateur de fichiers |
| ⊞ + I | Ouvrir les Paramètres |
| ⊞ + L | Verrouiller l'écran |
| ⊞ + D | Afficher le bureau |
| ⊞ + V | Historique du presse-papiers |
| ⊞ + . | Emojis |
| ⊞ + Maj + S | Capture d'une partie de l'écran |
| ⊞ + Tab | Voir toutes les fenêtres |
| ⊞ + flèches | Coller une fenêtre à un bord |
| Ctrl + Maj + Échap | Gestionnaire des tâches |

## Les archives

L'Explorateur de fichiers ouvre les archives ZIP, 7z, RAR, tar et
d'autres comme des dossiers, même un fichier qui a perdu son extension.
Clic droit dessus pour **Extraire tout…**, **Extraire ici** ou
**Extraire dans un nouveau dossier**.

Pour en créer une, sélectionnez vos fichiers, clic droit, puis
**Compresser en** et choisissez ZIP, 7z ou tar.zst.
**Options supplémentaires…** ouvre la fenêtre **Ajouter à l'archive** :
niveau de compression, mot de passe, découpage en plusieurs parties.
Les fichiers RAR s'ouvrent mais ne peuvent pas être créés, le format
étant fermé : créez plutôt un 7z.

## Les mises à jour

La plupart des mises à jour s'installent toutes seules, pendant que vous
travaillez. Celles qui demandent un redémarrage l'attendent, et le
disent. Avant chaque mise à jour, Raye garde une copie du système : si
une mise à jour pose problème, on peut revenir en arrière. Voir
[Les mises à jour](03-mises-a-jour.md).
