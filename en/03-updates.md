# Updates

Raye keeps itself up to date without getting in your way.

- **Security fixes** install on their own, in the background.
- **Other updates** download when it is a good moment: plugged in, on a
  connection that is not metered, no game running. Most then install
  right away, while you work, with nothing to restart.
- A few, security fixes included, need a restart: the kernel, drivers,
  firmware and the desktop itself, because the running system keeps them
  loaded. Each one is marked **Restart required**, and they install when
  you choose **Update and restart** in Start, or **Restart now** in the
  notification or in Settings.
- Before each update, Raye keeps a **snapshot of the system**. If an
  update causes trouble, **Settings → System → Recovery** takes the system
  back to before it.

Everything shows in **Settings → Raye Update**: what is waiting, the last
check, and **Install now** when nothing needs a restart, so you do not
have to wait for the next good moment.

## Pausing updates

In **Settings → Raye Update**, pick **1 to 5 weeks**, then **Pause**. While
paused nothing is checked or downloaded, except security fixes, which
keep coming. **Resume updates** ends the pause whenever you like.
