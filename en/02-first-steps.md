# First steps

## The desktop

The bottom bar works like the one you know: the button with the Raye eye
opens the Start menu, open apps sit in the middle, the clock, network and
sound on the right.

## Shortcuts

| Keys | What it does |
|---|---|
| ⊞ | Open the Start menu |
| ⊞ + E | Open the file explorer |
| ⊞ + I | Open Settings |
| ⊞ + L | Lock the screen |
| ⊞ + D | Show the desktop |
| ⊞ + V | Clipboard history |
| ⊞ + . | Emoji |
| ⊞ + Shift + S | Screenshot of part of the screen |
| ⊞ + Tab | See all windows |
| ⊞ + arrows | Snap a window to an edge |
| Ctrl + Shift + Esc | Task Manager |

## Archives

File Explorer opens ZIP, 7z, RAR, tar and other archives like folders,
even a file that has lost its extension. Right-click one for
**Extract all…**, **Extract here** or **Extract to a new folder**.

To make one, select your files, right-click, then **Compress to** and
pick ZIP, 7z or tar.zst. **Additional options…** opens the
**Add to archive** window: compression level, a password, split parts.
RAR files open but cannot be made, since the format is closed: make a 7z
instead.

## Updates

Most updates install by themselves, while you work. The ones that need a
restart wait for one, and say so. Before each update Raye keeps a copy of
the system: if an update causes trouble, it can be rolled back. See
[Updates](03-updates.md).
